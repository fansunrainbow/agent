# Stage 5 测试矩阵

| 类别 | 代表输入 | 期望 |
|---|---|---|
| 简单查询 | 南京客户有多少 | `customer_count` + 南京过滤，校验通过 |
| 复杂筛选 | 2024年Q1南京女性客户日均资产超过100万 | 时间、指标阈值、枚举、城市均落入计划 |
| 排名 | 交易金额最高的前10个产品 | 产品主题、降序、limit=10 |
| 口径歧义 | 平均资产 | 同时询问指标口径和统计时间 |
| 未知语义 | 火星能量值超过10的客户 | 不创建新指标，进入澄清 |
| 动态实体 | 持有9900000209的客户 | 从 `dim_product` 解析，不依赖硬编码名称 |
| 同名实体 | 持有建板花旗六乙购Ａ的客户 | 返回至少两个候选，强制澄清 |
| 多轮上下文 | 南京客户数量 → 改为苏州 | 保留指标，仅替换城市过滤 |
| 修复 | 操作符 `=` | 规范化为 `eq`，修复上限为2 |
| LLM 防绕过 | Provider 返回未知指标 | Stage 4 校验拒绝并澄清 |
| 幻觉基准 | 两个正常计划 | 未注册语义计数和比率均为0 |

运行：`python -m pytest -q`。
